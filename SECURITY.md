# Security policy

Please do not report suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/fangwd/sqlex/security/advisories/new

Include the affected sqlex version, database and driver, impact, reproduction,
and any known mitigation. Do not include production credentials or private
data.

Security fixes target the current major release. Users should run the latest
patch version and review database-driver security advisories independently.
